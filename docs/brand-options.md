# CircleMate 品牌候选

以下是命名方向草案。暂未核查商标、域名或 Chrome Web Store 名称是否可用。

| 英文名 | 中文名 | 适合的产品印象 |
| --- | --- | --- |
| CircleMate | 圈友 | 友好、面向新手，适合从关系整理扩展到互动和内容建议。当前推荐。 |
| XCompass | X罗盘 | 新手运营指南，适合未来扩展成完整的 X 教练。 |
| LinkUp | 连友 | 短、好读，强调建立连接；名称较常见。 |
| OrbitMate | 轨友 | 有科技感，表达围绕兴趣建立关系；首次看到时不够直观。 |
| SocialPilot | 社交领航 | 表达运营辅助，适合更宽的创作者工具；名称较通用。 |

## 当前工程名

工程目录和插件显示名暂用 CircleMate，中文展示名暂用“圈友”。正式推广前可统一替换 manifest、页面文案、商店素材和目录名。
