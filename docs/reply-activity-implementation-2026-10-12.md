# 今日回复同步与时间线标记

沿用已验证 CreateTweet 发送及作者、目标帖子、正文核验，不新增 X 接口。成功回复使用原生响应 legacy.created_at；字段缺失时使用确认时间。界面只在 confirmed=true 时清除草稿并收起。

confirmedReplies 按账号持久化 reply ID、目标 post ID 和时间，不保留回复正文。保留最近七天、最多 5000 条。回复意图的重入去重沿用原有 token，计数和原生创作同步按回复 ID 合并。同步重启、分页更新不会覆盖已确认的本地回复，也不会重复计数。

北京时间当天创建的回复参与指标和标记；午夜前创建、午夜后才收到成功响应的回复不会计入新的一天。统计未完成时仍是已采集数量，不承诺完整覆盖所有原生回复。原生同步取得的 in_reply_to_status_id_str 用于标记目标帖子；没有记录的帖子不标成未回复。

首页推荐、关注及个人时间线复用相同编辑器。快速回复图标显示绿色勾和“今日已回复”提示，允许再次回复。页面首次读取当前账号缓存，storage 更新跨页面传播，账号切换清除原标记，分钟检查清除跨日标记。

167 项测试通过，覆盖确认/未确认编辑器、重复 token、原生同步去重、跨日和计数。无真实 X 写入的本地浏览器测试已验证发送成功自动收起及刷新后保留标记；未为测试发布新的真实回复。
