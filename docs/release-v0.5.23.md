# v0.5.23 · 资料卡即时互动

撤掉素材箱和待回复列表。之前保存的本地记录保留在备份中。

群成员悬浮资料卡增加“最近帖子”入口，按需读取最近三条原创或引用帖，排除回复、转帖、广告与嵌套引用内容。固定互动区域支持刷新、点赞及取消点赞，关闭悬浮卡不销毁已打开的互动区域。

回复使用 X 原生小窗口，并携带目标帖子编号；群列表保留在原页面。发送与附件由 X 原生编辑器处理。

点赞写请求只发送一次，响应与独立读取均核验后更新状态。结果不明保留待核验记录，按钮锁定，禁止自动重放。请求限流显示错误和冷却提示。
