# 时间线内嵌回复验证

## 实现范围

- `/home`：推荐与关注共用入口。
- 个人主页及回复、媒体等个人时间线。
- 排除帖子详情、搜索、通知及原生弹窗中的帖子。

内容脚本和后台共用 `src/shared/timeline-context.js` 的路由规则。时间线回复复用群成员最近帖子面板的输入组件及已验证的 CreateTweet 请求，未新增猜测端点或参数。

发送前由后台重新检查当前页面的原生帖子时间链接、作者、帖子 ID 与原生回复按钮状态。只匹配外层帖子，排除引用帖目标。账号检查、持久化发送意图和重复提交保护沿用现有逻辑。

## 验证结果

153 项自动化测试通过。新增测试覆盖路由范围、时间线目标核验、引用帖排除、禁用回复按钮、无目标时不发送，以及相同提交令牌去重。

本地浏览器界面测试通过：首页展开、切换帖子恢复草稿、模拟发送确认后清空、个人时间线展开。模拟发送不会访问 X。

本次真实 Chrome 页面测试被其他扩展浮层阻断，需关闭浮层、重载插件并刷新页面后继续验证。尚未宣称本次首页与关注时间线真实发送通过。底层发送接口的此前真实请求证据见 `inline-reply-research-2026-10-07.md`。
