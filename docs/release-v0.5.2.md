# 0.5.2 队列与恢复完善

- 分离队列执行器，后台共享串行调度器每轮重新读取账号缓存，避免多标签重复执行同一意图。
- 标签页关闭时清理该页定时器和闹钟，唤醒其他 X 标签页；执行时仍按当前登录账号读取队列。
- 冷却等待取账号级与任务级重试时间的较晚值，唤醒后不会提前写入。
- 清理历史保留所有未完成和结果待确认的意图。500 人上限包含待确认项，防止历史裁剪绕过重复写保护。
- 运行中任务重启只读取关系核验，暂停队列仍保持暂停；历史意图账号不匹配时取消，不执行。
- 备份导入增加群成员 ID 与队列状态校验；修正异常筛选的人数提示。

120 项测试通过。新增执行器测试验证了两个标签调度同一任务只执行一次、跨账号隔离、原标签关闭后接续、跨冷却期限唤醒、暂停时恢复核验及外来账号意图取消。存储测试验证一次保存失败后旧记录仍可读，后续保存可写入变更。

上述测试使用受控会话和存储，不是实际 Chrome 休眠或配额耗尽的证明。仍需验证安装后插件完整写入流程、大群滚动性能、真实限流，以及实际升级恢复。
