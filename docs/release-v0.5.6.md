# 0.5.6 分析缓存解析版本

重新捕获原生分析 HTTP 200，保存不含账号身份的完整时间序列与 legacy 关注变化样本。实际解析结果仍为新增 399、流失 16、净增 383；两个输入没有随指标卡片删除。

此前只按 fetchedAt 判断分析缓存有效期。更新解析规则后，旧版本存下来的 null 可能仍在一小时有效期内，不会自动重算。现在分析结果记录 parserVersion，旧解析版本自动刷新，并优先于未完成名单分页执行；真实限流冷却仍遵守。未来解析变更可通过递增版本触发刷新。

125 项测试通过，包括完整抓包样本经过解析与序列化后的净增结果、未过期旧缓存升级刷新以及限流保护。旧版本结果仍保留到新请求成功，不清空其他缓存。缺失净增的鼠标提示说明两个输入尚未完整。
