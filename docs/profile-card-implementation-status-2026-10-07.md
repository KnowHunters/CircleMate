# 资料卡即时互动实现与验证 · 2026-10-07

## 功能

移除素材箱、待回复列表、帖子收集图标和对应消息入口。保留旧本地数据与备份验证。

群资料卡增加最近帖子入口；点击后打开固定互动区域。读取按账号和目标成员缓存 60 秒，最多缓存 100 位成员，刷新绕过缓存。没有遍历全部群成员请求帖子。结果通过账号、群聊及请求代次核对，过时响应不显示。

原生 UserOriginalsTimeline 请求仍为 count=20，展示最近三条原创或引用帖。真实响应中存在会话模块回复，解析时排除回复、转帖、广告与引用的嵌套内容；核对作者，按编号去重，按发布时间排序。旧置顶帖不会挤占最近三条。媒体目前显示提示及原帖链接。

点赞复用原生 JSON POST 形状；发送前读取最新状态，发送一次后独立重读确认。未确认意图持久化，重启后不会重放。限流和明确拒绝清理未执行意图；超时或不明结果锁住按钮，需刷新核验。

回复打开带目标编号的 X 原生小窗口，用户在原生编辑器中发送；没有实现或猜测直连发送接口。这样保留群列表与位置，并让 X 负责草稿、附件和回复权限。
