## 使用与数据范围

帖子指标区域增加收集图标，可选择存为素材或稍后回复。数据页的创作收集卡片默认折叠，分素材箱、待回复和已处理。

每个账号最多保存 300 条，按帖子编号去重，笔记最多 2000 字。记录按当前登录账号隔离，纳入现有备份。保存的是页面可见正文，媒体和折叠长文通过原帖查看，不声称保存完整媒体或全文。

没有增加 X 写接口。待回复列表通过原帖链接访问帖子，已回复状态由用户手工标记。既有时间线快捷回复继续使用原生按钮。

## 验证

131 项 Node 测试通过，包含去重、状态切换、账号隔离、无效输入、容量及备份验证。构建通过。尚需连接已登录 X 的浏览器，实测图标布局、点击收集、关闭重开、切换账号及原生回复流程。本轮不能代替这些验证。
