# 0.5.0 审查与修复记录

## 已完成

- 关注、回关、取关共享账号级持久队列。关闭群列表后保留排队状态，支持暂停、恢复和取消等待任务。
- 队列按账号与成员去重，阻止相反操作同时排队；限流遵守服务端重试时间。结果不明时先核实关系，不重复发送写请求。
- 后台重启后对运行中任务读取资料核验，不重放历史写请求。备份恢复也不自动执行旧队列。
- 关系识别统一使用本地索引、完整名单与带时间的直接证据。名单扫描开始时间决定证据优先级，避免晚结束的旧扫描覆盖新关注操作。
- 异常账号保存到账号缓存，正常关系筛选排除异常成员；可单独读取资料核实恢复。
- 名单完整时本地对比；未知成员每轮只补全一人，后台调度让用户操作优先执行。开放 Shadow DOM 增量扫描，避免重复遍历。
- 缓存按账号隔离、成员分桶保存，投影带修订号；升级保留原账号存储键。迁移先备份，存储失败保留原数据。
- 导入备份校验账号和结构，清除运行能力标记；界面提供备份导出、恢复及同目录升级说明。
- 回关列表复用行节点，保持滚动与操作状态；确认框共享样式，状态文字保持可读。
- 分析只显示已验证指标，缺字段保持未知。上一周期使用真实的 previous_totals，小时回填不重复累加；曝光支持 K/M。
