# CircleMate｜圈友

0.5.16 提供账号隔离缓存、群成员本地关系识别、持久操作队列与创作分析。数据页分析卡片支持折叠，三行三列指标，更新时间位于标题区。自动同步读取数据，关注、回关和取关仅执行用户明确提交的任务。

## 安装与升级

从 [GitHub Releases](https://github.com/KnowHunters/CircleMate/releases) 下载版本 ZIP。源码测试与构建使用 Node.js 22，无需安装第三方依赖。推送到 main 后自动验证；推送与 package.json 版本一致的 v 标签后自动发布 ZIP。

运行 `npm run build`，生成 dist 和版本 ZIP。解压到固定目录，在 Chrome 扩展管理页加载该目录。

升级时覆盖同一目录，点击扩展“重新加载”，再刷新 X 页面。无需卸载，原账号缓存保留。可先在“说明”导出备份；恢复备份不会启动历史队列。

## 当前功能

- 实时：账号关系、北京时间今日原创/回复/转帖；关系同步、群成员数据、默认折叠的待回关列表。
- 数据：固定指标、创作与曝光趋势。分析采用 UTC 日桶，缺失数据保持未知，大数使用 K/M。
- 所有成员：关系与蓝V筛选、异常列表；隐藏自己，名单完整时本地识别。群首页不注入筛选区。
- 操作队列：账号级持久化、随机间隔、限流冷却、暂停/恢复/取消。结果不明先核实，不重复发送。
- 异常账号：根据结构化不可用响应缓存；正常关系筛选排除异常成员，支持独立核实。
- 原生手工关系操作：观察成功请求并核实对应成员，不重读整个成员列表。

账号资料有效期 15 分钟，分析 1 小时，关系名单 6 小时。分页保存游标，失败保留缓存，限流遵守服务端时间；没有已登录 X 标签页时停止请求。

## 真实证据与验证范围

原生取关在两个不同账号实测，测试后均重新关注并核验恢复。destroy.json 返回 HTTP 200，但 following 仍为 true；重新读取资料才返回 false。直连使用抓包参数，遇到旧状态再读取资料确认。

分析采用真实 previous_totals 与关注变化字段。当前捕获的名单未提供已核验的历史关注时间，界面显示本地成功确认时间。缺字段不填零。

`npm test`：127 项通过，包含队列调度、多标签账号隔离、冷却恢复与存储失败。真实原生请求核验与测试均已记录；插件安装后的完整端到端写入、浏览器休眠和多标签账号切换仍需场景验证。
