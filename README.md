# 圈友 CircleMate

在 X 上找到想关注的人，整理账号关系，查看创作表现。

圈友是一款 Chrome 扩展。登录 X 后，你可以查看待回关用户，在群成员列表中筛选未关注、未回关和蓝 V 账号，也可以查看帖子、曝光和互动趋势。

[下载最新版本](https://github.com/KnowHunters/CircleMate/releases/latest)

## 你可以用它做什么

- **找出待回关的人**：查看关注了你、但你尚未关注的用户。结合简介判断是否回关。
- **筛选群成员**：打开群聊的“所有成员”，筛选未关注、未回关、蓝 V 或异常账号，减少逐个查看的时间。
- **管理关注操作**：点击关注或回关后，查看排队、执行和等待状态。有任务时可以暂停、恢复或取消执行。
- **查看账号近况**：在“实时”页查看关注人数、关注者人数，以及今天发布的帖子、回复和转帖。
- **复盘创作表现**：在“数据”页查看帖子、回复、曝光、点赞、收藏、转帖、引用和净增关注者，结合趋势图了解变化。

## 安装

1. 在[下载页面](https://github.com/KnowHunters/CircleMate/releases/latest)下载 `circlemate-v版本号.zip`，解压到一个固定文件夹。
2. 在 Chrome 地址栏输入 `chrome://extensions/`，打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择解压后的文件夹。
4. 打开或刷新 [X](https://x.com)，登录你的账号。

安装后请保留这个文件夹，Chrome 会从中读取扩展。

## 开始使用

**先同步关系。** 登录 X 后，圈友会自动同步账号数据。你可以在“实时”页展开“关系同步”，查看进度或手动同步。名单同步完成后，成员筛选和待回关列表会更完整。

**再筛选成员。** 打开 X 群聊信息，进入“所有成员”。使用顶部筛选按钮查找用户；蓝 V 默认勾选，取消勾选即可查看其他成员。向下滚动可以加载更多成员。

**按需关注或回关。** 点击相应按钮提交操作。任务会依次执行；如果 X 限制操作频率，界面会显示等待状态。你可以暂停、恢复或取消尚未执行的任务。

**查看创作数据。** 切换到“数据”页查看指标和趋势。卡片可以折叠，点击刷新按钮可更新分析数据。`—` 表示暂时没有数据，数值 `0` 表示已获取的数据为零。

## 数据与备份

账号和群成员记录保存在当前浏览器中，不同 X 账号的数据分开保存。你可以在“说明”页导出或恢复备份。

群成员数量以已加载的记录为准。关注时间仅记录圈友确认成功的本地操作时间，无法补全过去所有关注的时间。

## 升级

下载新版 ZIP，解压并覆盖原扩展文件夹。在 Chrome 扩展管理页点击圈友的“重新加载”，然后刷新 X 页面。

无需卸载，原有缓存会保留。升级前也可以在“说明”页导出一份备份。
