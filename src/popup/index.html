项目信息圈友 (CircleMate)

在本机整理 X 账号关系、筛选群成员、管理关注队列，查看创作与曝光趋势。

GitHubKnowHunters/CircleMate↗Twitter / X@jiaoxiawo↗Telegram@jiaoxiaow↗加入 X 群聊交流与反馈↗
开始使用
  1. 打开 X 群信息并展开成员列表。
  2. 登录后自动同步关注与粉丝名单。
  3. 查看未关注成员，逐个关注；在数据页复盘创作。

数据保存在本机。部分采集不代表完整名单；未知关系不会显示为未关注。

安装或更新后刷新 X 页面，登录后即可同步。

升级时将新版文件覆盖到原扩展目录，在 Chrome 扩展页点重新加载，再刷新 X 页面。无需卸载。
